# ACA3DHUD

> `UI/CA3DHUD.h/.cpp` · AHUD — 클라 전용

## 역할
- 매치 위젯 수명: 생성 → 뷰포트 부착 → 결과 전환 위임
- WBP 없을 때 캔버스 텍스트 폴백 (non-Shipping)
- 표시 가공은 안 함 — 위젯의 순수 함수 소관

## 왜
- **왜 수명/내용 분리?** → WBP 교체가 자유로우려면 HUD는 "만들고 보여주기"만
- **왜 폴백?** → WBP(에디터 작업) 전에도 값이 보여야 개발이 안 막힘.
  실증: 에디터 작업 0으로 스크린샷 검증
- **왜 폴백이 위젯 순수 함수를 통과?** → 폴백 전용 로직 = 두 벌. 공유하면 항상 같은 값
- **왜 cvar 3모드(-1/0/1)?** → 자동(위젯 없을 때만)이 기본, 강제는 비교 검증용
- **왜 데디 가드 이중?** → 엔진이 안 만들지만 BeginPlay 가드 한 겹 더 (GDD 7.4)
