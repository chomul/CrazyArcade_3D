# APredictedBombVisual

> `Source/CrazyArcade3D/Gameplay/Bomb/PredictedBombVisual.h/.cpp` · AActor, `bReplicates=false`, IPooledActor

클라 전용 폭탄 설치 예측 비주얼. **로직 0** (제자리 회전만). `Cell`이 진짜 폭탄과의 매칭 키.

## 왜 이렇게 했는가

- **불변식 3의 실체: 예측 폭탄은 타이머를 돌리지 않는다** — 타이머·판정·연쇄는 100%
  서버 `ABomb` 소유. 예측에 "상태"가 없으므로 서버가 거부하면 이펙트만 지우면 끝 —
  되돌릴 것이 없어 상태 불일치가 **원천적으로** 불가능하다.
  예측 넷코드의 어려움은 "예측이 틀렸을 때 되감기"인데, 되감을 것을 안 만들면 문제가 사라진다.
- **왜 존재하나 — RTT 은폐** — 설치 입력 후 서버 확정까지 왕복 지연 동안 아무것도 안 보이면
  조작감이 죽는다. 즉시 보여주고, 진짜가 오면 같은 셀의 예측을 회수해 교체한다.
- **`Cell`이 매칭 키인 이유** — ID 발급·왕복 없이, "같은 셀에 진짜가 왔다 = 내 예측이
  확정됐다"로 충분하다. 같은 셀 중복 예측은 로컬 검증이 미리 막는다.
- **풀링하는 이유** — 복제 없는 순수 시각 액터라 풀링 안전(프로젝트 규칙: 풀링은 클라
  시각 요소만). 설치는 빈번하므로 스폰 비용을 아낀다.
- **회전 틱이 있는데 불변식 3 위반이 아닌가?** — 판정 상태를 바꾸지 않는 시각 회전뿐이다.
  테스트도 "틱 100회 실행 후 회전 외 상태 변화 0"을 검사하는 방식으로 강화돼 있다.
- **리슨 호스트는 예측을 생략** — `HasAuthority()`면 서버 경로 직행. 서버에서 예측을 만들면
  진짜와 예측이 같은 화면에 둘 다 뜬다.
