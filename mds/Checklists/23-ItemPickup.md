## 동작 검증 — 자동화 (2026-08-02 · `CrazyArcade3D.Gameplay.ItemPickup` 통과, 전체 16스위트 실패 0)
- [x] 같은 Seed ⇒ 같은 배치 / 다른 Seed ⇒ 다른 배치 (불변식 4)
- [x] 아이템은 **Destructible 셀에만** 배치된다
- [x] 파괴 → 노출 스폰 / **자기를 드러낸 폭발에 즉사하지 않는다** (소멸 → 노출 순서 회귀)
- [x] 물줄기 소멸은 효과 없음 (스탯 불변)
- [x] `Alive` 만 획득 — **`Trapped`·`Dead` 는 획득 실패** (스탯 불변 + 아이템 잔존)
- [x] Cap 클램프 — `MaxBombCountCap`·`MaxBombRangeCap`·`MoveSpeedMulCap`
- [x] 니들: 획득 → 갇힘 → 수동 사용 → 탈출 + **1회 소모**(두 번째 무시) + 갇힘 타이머 해제
- [x] 킥: `bHasKick` 만 서고 다른 스탯 불변

## 동작 검증 — 데디 서버 실전 (2026-08-02 · 봇 6대, 사람 입력 0, 220초)
- [x] Destructible 파괴 → 아이템 노출 스폰 (노출 7건)
- [x] **봇이 실제로 밟아 획득** (4건 — 니들·킥·풍선·물약). 컬리전 분리가 데디에서 동작함을 증명
- [x] 물줄기에 닿은 아이템이 효과 없이 소멸
