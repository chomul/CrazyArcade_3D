# Checklist 23 — ItemPickup

> 대응 Task: `mds/Tasks/23-ItemPickup.md`
> **PIE를 실제로 돌리지 않은 항목은 체크하지 않는다 — 미검증으로 남긴다.**

## 빌드 (필수 게이트)
- [ ] `CrazyArcade3DEditor` 빌드 통과
- [ ] `CrazyArcade3DServer` 빌드 통과
- [ ] 프로젝트 파일 재생성 실행

## 코드 검증 (정적)
- [ ] 획득·소멸 판정이 서버 전용 (오버랩 핸들러 권한 가드)
- [ ] 효과 적용이 `StatusComponent::ServerApplyItem` 경유 — 아이템에 스탯 로직 없음
- [ ] `OnRep_Type` 시각 처리에 데디 가드
- [ ] 드랍률·낮은 니들 확률이 룰셋/생성기 소관 (액터에 하드코딩 없음)

## 동작 검증 (PIE 필수 — 미실행 시 미검증)
- [ ] Destructible 파괴 → 예약된 아이템 노출 스폰
- [ ] 풍선 획득 → 폭탄 개수 +1 (복제 확인)
- [ ] 물약 획득 → 범위 +1 / 롤러 → 속도 증가 체감
- [ ] 니들: 갇힘 → 탈출 → 소모 (재사용 불가)
- [ ] 킥: `bHasKick` 플래그 획득 (차기 동작은 구현 범위 확인 후 — 미구현이면 미검증 명시)
- [ ] 물줄기에 닿은 아이템이 효과 없이 소멸
- [ ] Cap 초과 획득 시 클램프
- [ ] (Listen+클라) 획득·소멸이 전 클라에서 동일하게 보임

## 결정 대기 (사용자 확정 전 미검증)
