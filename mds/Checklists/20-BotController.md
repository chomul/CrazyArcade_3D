# Checklist 20 — BotController

> 대응 Task: `mds/Tasks/20-BotController.md`
> **PIE를 실제로 돌리지 않은 항목은 체크하지 않는다 — 미검증으로 남긴다.**

## 빌드 (필수 게이트)
- [ ] `CrazyArcade3DEditor` 빌드 통과
- [ ] `CrazyArcade3DServer` 빌드 통과
- [ ] 프로젝트 파일 재생성 실행

## 코드 검증 (정적)
- [ ] BT/블랙보드 미사용 — 순수 C++ FSM
- [ ] 서버 가드 (클라에서 봇 로직 실행 안 됨)
- [ ] 위험/설치 판단이 `Propagate` 재사용 — 봇 전용 판정 로직 없음
- [ ] 조작이 캐릭터 공용 함수(Move/DoJump/ServerPlaceBomb) 경유 — 치트 경로 없음
- [ ] BFS 방문 순서 결정론적 (고정 방향 배열)

## 동작 검증 (PIE 필수 — 미실행 시 미검증)
- [ ] 인원 부족 시 GameMode가 봇으로 채움 (최소 2인 시작)
- [ ] 봇이 이동·점프(층간 포함)·폭탄 설치를 수행
- [ ] 봇이 자기 폭탄 프리뷰 범위 밖으로 대피
- [ ] 봇이 물줄기에 갇히고 죽는다 — 플레이어와 같은 판정 경로 실증
- [ ] 봇 포함 매치가 끝까지 진행돼 승자 판정
- [ ] 봇 4대 동작 중 서버 `stat unit` 스파이크 없음
