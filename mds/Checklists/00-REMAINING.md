# 남은 미검증 항목 — 통합 색인 (2026-08-10 기준)

> 코드는 다 됐다. 자동화 **30스위트 실패 0**, 두 타깃 빌드 통과, 데디 봇 매치 완주.
> 여기 남은 것은 전부 **사람이 붙어야만 닫히는 것**이다.
>
> 번호별 체크리스트를 돌아다니지 말고 이 문서로 판단하라 — **세션 종류별로 묶었다.**
> 한 번 띄우면 그 묶음이 통째로 닫힌다. 원문·근거는 각 항목 뒤 `[NN:줄]` 참조.

## 먼저 알아야 할 것 — 왜 자동화가 못 잡나

| 못 잡는 이유 | 해당 묶음 |
|---|---|
| **넷드라이버가 없다** — 헤드리스 단독 세션은 서버=클라라 복제가 성립조차 안 한다 | 세션 A |
| **`IsRunningDedicatedServer()` 가 PIE 에서 false** — 에디터 프로세스라 데디 가드가 안 걸린다 | 세션 B |
| **입력이 없다** — 봇만 도는 세션에는 Q/E·이동을 누르는 사람이 없다 | 세션 C |
| **취향은 코드가 아니다** — "재미있나"는 통과/실패가 없다 | 세션 C 밸런스 |

이 프로젝트는 **"PIE 는 실제 런타임보다 관대하다"** 로 세 번 물렸다 (HISM 컬리전 · `bReplicateMovement` ·
스폰 낙사). 세션 B 는 그 세 번째를 막으려고 따로 떼어 둔 것이다 — **PIE 로 대신할 수 없다.**

## 세션 A — 리슨 호스트 + 클라 1대 (⭐ 가장 많이 닫힌다)

**한 판이면 아래가 전부 닫힌다.** 실제 버그가 나올 가능성이 가장 높은 묶음이기도 하다.

- [ ] **나간 사람이 결과 화면에 `(탈주)` 로 뜨는가** — 한쪽 창을 그냥 닫아 본다 [35:75]
- [ ] 나간 사람의 폰이 **다른 클라 화면에서도** 사라지는가 [35:77]
- [ ] **설치자가 설치음을 한 번만 듣는가** — 예측 시점과 서버 확정 시점 두 경로가 있어
      **멀티에서만** 중복이 드러난다. 단독 세션은 예측을 만들지 않아 검증이 성립하지 않는다 [31:99]
- [ ] 남의 캐릭터를 **관전**했을 때 90도 스냅 고정 내려보기가 유지되는가 [30:191]
- [ ] 가림 페이드가 **각자 자기 카메라 기준으로만** 도는가 — 남의 캐릭터 앞은 안 뚫려야 정상 [27-Occ:124]
- [ ] 클라가 시드로 **같은 절차 맵**을 만드는가 (해시 일치) [22:64]
- [ ] 두 사람이 **서로 다른 스폰 셀**에 뜨는가 [32:100]
- [ ] 사망 시 `bAlive`·`FinalRank`·`AliveCount` 가 전 클라에 복제되는가 [18:26]
- [ ] `ColorIndex` 가 접속 순서대로, 전 클라에서 동일하게 보이는가 [18:25]
- [ ] 갇힌 상대를 **실제 CMC 로 밀었을 때** 접촉 판정이 매 프레임 안정적인가 [33:83]

## 세션 B — 진짜 데디 서버 exe + 클라 (PIE 로는 절대 안 잡힌다)

쿡·스테이징 절차는 `dedi-server-windows.md`. **언쿡 실행은 불가 판명**(엔진 구조 문제).
전부 "서버에서 **돌지 말아야 할 것**이 안 도는가" 다 — GDD 7.4.

- [ ] 사운드·나이아가라가 **서버에서 실행되지 않는가** [31:101]
- [ ] 서든데스 **마커 스폰이 스킵**되는가 [24:52]
- [ ] 가림 페이드 컴포넌트가 **아무것도 안 하는가** [27-Occ:125]
- [ ] 관전 경로가 서버에서 **no-op** 인가 [29:76]
- [ ] 사망 시 **시각 처리(액터 숨김)가 실행되지 않는가** [27-Death:35, dedi:86]
- [ ] ⚠️ 반대로 **꺼지면 안 되는 것**: 폭탄 **낙하 중 틱이 유지**되는가
      (`ServerRefreshMovementTick` — 꺼지면 폭탄이 공중에 박힌다) [30:194]
- [ ] ⚠️ 같은 성격: **킥이 데디에서 동작**하는가 (킥도 틱을 다시 켜는 경로다) [28:84]

> 마지막 두 개가 이 묶음의 핵심이다. 나머지는 "안 도는 것 확인"이라 실패해도 성능 손해지만,
> 이 둘은 **실패하면 게임이 깨진다.** HISM 컬리전 사건과 같은 계열 — "데디에서는 끄자"가
> 실제로는 켜져 있어야 했던 자리.

## 세션 C — 혼자 `-game` 또는 패키징 빌드 (체감·입력)

### C-1. 실제로 결함일 수 있는 것
- [ ] **패키징 빌드로 시작해 살아 있는가** — 스폰 낙사 수정의 최종 확인. 헤드리스는 입력이 없고,
      **PIE 는 `APlayerStartPIE` 때문에 면역**이다 [32:99]
- [ ] Q/E **4방향 순회**가 되는가 · 회전 중 이동 입력이 끊기지 않는가 [11:22-23]
- [ ] **관전 중** Q/E 회전 [30:185]
- [ ] 계단으로 2층 도달 · **2블록 벽은 못 오름** · 맵 밖 추락 시 KillZ [10:23-25]
- [ ] 서든데스 예고 마커가 **정확히 그 칸**을 부수는가 (마커 ≠ 낙하 칸이면 실패) [24:45]
- [ ] 구멍 낙사가 `EDeathCause::SuddenDeath` 로 집계되는가 [24:49]
- [ ] `Kick`·`SuddenDeathWarn` 큐 실전 발화 — 아직 조건이 안 나왔다 [31:95]
- [ ] 마지막 한 명만 남고 나머지가 전부 나갔을 때 결과 화면 전환 [35:79]

### C-2. 취향·밸런스 (정답이 없다 — 사용자 판단)
- [ ] **서든데스를 보고 피할 수 있는가** — 이게 그 설계의 전부다 [24:48]
- [ ] 서든데스 페이싱 — 맵이 줄어 매치가 실제로 끝나는가 [24:50]
- [ ] **90도가 45도보다 나은가** (사각지대 체감) [30:188]
- [ ] 낙하 속도 12칸/초 — "밀었는데 사라진 것처럼" 보이지 않는가 [30:193]
- [ ] 절벽으로 폭탄을 밀어 **협곡 바닥에서 터뜨리는 플레이**가 성립하는가 [30:192]
- [ ] 봇이 후반에 **실제로 강해진 게 느껴지는가** / 파밍이 과해 겉돌지 않는가 [34:81-82]
- [ ] 갇힘이 너무 가혹하지 않은가 — 익사가 0건이 됐다 [33:79,84]
- [ ] 아이템 5종이 **한눈에 구분**되는가 [31:51]
- [ ] 가림 페이드 정도·속도 [27-Occ:123]
- [ ] 6층 지형에서 점프·카메라 체감 [22:62]
- [ ] 봇 움직임이 자연스러운가 · `stat unit` 스파이크 없는가 [20:46-48]

**손잡이(코드 수정 불필요, 전부 `DA_Rules_Default`)**
