      렌더링 사정이 게임 규칙에 새어 들어오는 것도 막는다
- [x] **플레이어만 그리드에 없다** → `GetFootCell()` 로 셀 변환해 비교. 피격 판정과 같은 정의를
      공유한다 (좌표 공식을 다시 쓰면 언젠가 한쪽만 바뀐다). 시체는 제외 — "유령 방해 없음"
- [x] **프레임이 길어도 칸마다 판정** — 남은 거리로 한 번에 순간이동시키면 그 사이의 벽·폭탄·

- [x] **레지스트리를 재등록하지 않는다** — `UExplosionSubsystem::FindBombAt` 이 셀을 키로 캐시하지
      않고 조회 때마다 `ABomb::GetCell()` 을 되묻는 구조라(**직접 코드로 확인함**) `Cell` 갱신이

- [x] `Cell` 을 `ReplicatedUsing=OnRep_Cell` 로 승격 — 위험 데칼이 폭탄을 따라간다.
      최초 복제(BeginPlay 이전)는 `HasActorBegunPlay()` 가드로 건너뛴다 (안 하면 데칼이 두 벌)
- [x] **`BlockingBox` 승격 로직 무수정** — 킥 없는 사람에겐 여전히 벽. 킥 경로는 그리드/레지스트리
      기반으로 완전히 분리돼 폭탄이 스스로 이동하므로 컬리전 응답과 무관
- [x] `ServerForceDetonate` 가 킥을 **먼저 멈춘다** — 연쇄 지연(`ChainStepDelay`) 동안 굴러가면
      실제 처리 시점의 셀이 달라져 "터진 자리"가 어긋난다
- [x] 데디에서도 동작 — `ServerStartKick` 이 틱을 켜고 `ServerStopKick` 이 되돌린다.
      이동은 시각이 아니라 물리·판정이다 (HISM 함정과 같은 계열)
- [x] `ABomb::Tick` 에 이동이 올라갔지만 **틱레이트가 규칙에 새지 않는다**: 이동이 서버 한 곳에서만
      돌고, 칸 판정은 셀 중심 도달 순간에만 일어난다 — 달라지는 것은 도착 시각뿐
