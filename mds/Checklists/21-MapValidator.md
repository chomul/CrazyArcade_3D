# Checklist 21 — MapValidator

> **자동화 테스트를 실제로 돌리지 않은 항목은 체크하지 않는다 — 미검증으로 남긴다.**

## 빌드 (필수 게이트)
- [ ] `CrazyArcade3DEditor` 빌드 통과
- [ ] `CrazyArcade3DServer` 빌드 통과
- [ ] 프로젝트 파일 재생성 실행

## 코드 검증 (정적)
- [ ] 전부 static 순수 함수 — 그리드 수정 없음
- [ ] GDD 4.2의 5개 검사가 각각 독립 함수
- [ ] `Validate` 실패 시 `OutReason`에 원인 기록
- [ ] 정수 연산·TArray만 (float/TSet 순회 없음), BFS 순서 결정론적
- [ ] 임계값이 파라미터로 노출 (하드코딩 없음)

## 동작 검증 — 검사별 통과/실패 쌍 (실행 필수 — 미실행 시 미검증)
- [ ] ① 층 도달성: 점프로만 닿는 2층 맵 통과 / 고립 층 맵 실패
- [ ] ② 스폰 거리: 충분히 떨어진 8스폰 통과 / 붙은 스폰 실패
- [ ] ③ 탈출로: 2방향 확보 통과 / 1방향 막힌 스폰 실패
- [ ] ④ 고립 구역: 정상 맵 통과 / 밀봉된 방 있는 맵 실패
- [ ] ⑤ 아이템 균등도: 고른 배치 통과 / 한 사분면 몰빵 실패
- [ ] `FallbackMapGenerator` 출력이 `Validate` 전체 통과
