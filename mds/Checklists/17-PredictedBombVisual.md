## 🏁 1주차 마감 게이트 — Listen Server PIE 2인 (설계서 5장 11번)
- [x] 두 클라가 설치·폭발·파괴 교환 후 **그리드 해시/덤프 완전 일치** — ✅ **통과 (2026-07-30, 3차 측정)**.
      구성: **데디 서버(PIE 0) + 클라 2(PIE 1·2)** — 두 플레이어가 모두 원격이라 리슨 구성보다 엄격한 경로.
      자동 해시 로그 대조 결과 **파괴 이벤트 10회 × 3인스턴스 = 30건, 불일치 0건, 누락 0건.**
      순번별로 세 인스턴스가 항상 동일: `#1` D9F06F8F(754칸) … `#10` 486E4312(740칸).
      → 지형 파괴가 서버·클라 전부에 동일하게 반영된다 (불변식 1의 단일 경로가 실측으로 증명됨).

      아래는 통과 전 무효였던 측정 2회 기록 (같은 실수 반복 방지):
      - **1차 (2026-07-30)**: `ca3d.GridHash` 를 호스트 창·클라 창에서 각각 실행했으나 **두 출력 모두
        `[클라이언트]`** — 콘솔 명령의 `World` 인자가 포커스 창과 무관하게 한 월드로 해석돼
        "같은 창을 두 번 읽은 값"이었다 (715E9F1C / 솔리드 737칸 → 비교 근거로 무효).
        → 명령을 **프로세스 내 전 인스턴스 순회 + 자동 일치 판정**으로 수정.
      - **2차 (2026-07-30, 데디 서버 PIE 0 + 클라 2)**: 명령은 정상 작동(3인스턴스 전부 `354BDDCD` ✅)
        했지만 **솔리드 756칸 = 초기 맵** — 파괴가 일어나기 전(22:43:50)에 쟀고 폭발은 22:45 부터였다.
        시드 기반 맵 생성의 결정론은 증명됐지만 **파괴 Multicast 경로는 검증되지 않았다** (게이트의 핵심).
      - **대책**: `AVoxelWorld::ApplyDestruction`(불변식 1의 단일 경로)이 **파괴 적용마다 인스턴스별
        해시를 자동 로그**하도록 변경 — `그리드 해시 #N [데디 서버 / PIE 0]: XXXXXXXX (솔리드 N칸 / …)`.
        서버·클라가 같은 함수를 통과하므로 같은 `#N` 끼리 대조하면 된다. 이제 콘솔 명령을 잊거나
        파괴 전에 재는 실수를 해도 근거가 남는다 → **평소처럼 2인 PIE 로 놀고 로그를 대조하면 종료.**
