- [x] 사망 처리가 **함수 하나에 모여 있다** — `ACA3DCharacter::ApplyDeathState`, 부활 시 되돌릴 항목을 헤드 주석에 목록으로 보존

- [x] 캐릭터를 파괴하거나 풀에 반납하지 않는다 (서버 권한 상태 액터 풀링 금지 — CLAUDE.md)

- [x] 사망 시 캡슐 컬리전 off, `MovementMode == MOVE_None`, **액터 숨김**(메시 컴포넌트 하나가 아니라 액터 단위 — BP 추가 메시 포함), 액터 파괴 없음
- [x] 사망 후 `ServerPlaceBomb` 거부 — 로그가 사유를 특정: `[Alive 0 / 슬롯 1 / Empty 1 / 폭탄없음 1]`

- [x] Trapped 상태에서는 이동이 여전히 가능 (실수로 막지 않았는지 — 대조군)
- [x] 클라 경로(`OnRep_Life`)도 서버와 동일하게 적용 — 컬리전·`MOVE_None`·메시 숨김
