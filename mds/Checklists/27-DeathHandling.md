# Checklist 27 — DeathHandling (사망 처리·관전)

> 대응 Task: `mds/Tasks/27-DeathHandling.md`
> **PIE를 실제로 돌리지 않은 항목은 체크하지 않는다 — 미검증으로 남긴다.**

## 빌드 (필수 게이트)
- [ ] `CrazyArcade3DEditor` 빌드 통과
- [ ] `CrazyArcade3DServer` 빌드 통과

## 코드 검증 (정적)
- [ ] 사망 처리가 **함수 하나에 모여 있다** (부활 시 되돌릴 항목이 흩어지지 않게 — Task 문서의 목록)
- [ ] 이동 차단은 `ACA3DCharacter::Move`/`DoJump` 에서 — 컨트롤러가 아니라 캐릭터 (봇도 같은 경로)
- [ ] 상태 변경(컬리전·이동 모드·LifeState)은 서버, 메시 숨김은 클라 `OnRep` — 불변식 5
- [ ] 메시 숨김 경로에 데디 서버 가드
- [ ] 캐릭터를 파괴하거나 풀에 반납하지 않는다 (서버 권한 상태 액터 풀링 금지 — CLAUDE.md)

## 동작 검증 — 자동화
- [ ] 사망 후 `Move`/`DoJump` 호출 → 위치·속도 불변
- [ ] 사망 시 캡슐 컬리전 off, `MovementMode == MOVE_None`
- [ ] 사망 후 `ServerPlaceBomb` 거부 (기존 Alive 검증 회귀)
- [ ] 중복 `ServerKill` 무시 (상태·GameMode 통지 1회)
- [ ] 갇힘(Trapped) 중 사망해도 갇힘 타이머가 남지 않는다

## 동작 검증 (PIE 필수 — 미실행 시 미검증)
- [ ] 죽으면 캐릭터가 화면에서 사라진다
- [ ] **산 사람이 죽은 자리를 통과할 수 있다** (유령 방해 없음 — GDD)
- [ ] 죽은 클라의 화면이 그 자리에서 매치를 계속 보여준다 (카메라 낙하·튐 없음)
- [ ] 죽은 뒤 이동·점프·폭탄 설치가 모두 먹지 않는다
- [ ] 데디 서버 로그에 시각 처리(메시 숨김)가 실행되지 않는다 (GDD 7.4)
